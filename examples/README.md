# 完整示例：传播学概论 COMM101

这是一次端到端演示：只给课程信息、课件要点和个人想法，跑完「建档 → 资料清单 → 复习资料 → pre PPT → 论文内容 → Word 材料 → 质检」全流程。

> 示例中的学校、课程、教师、学生、课件与数据均为虚构；教材与理论为真实内容。所有链接标注为示例、未核验。

## 三、这轮演示验证了什么

1. **资料清单先出**：三段式顺序固定，冲突与缺口单列，后续产出都要能指回清单编号（S1–S10）。
2. **课程类型分流**：水课场景下把论文放到最高优先级，短视频只占半天。
3. **按勾选产出**：五类交付物齐全，未勾选的内容（如封面格式、学校信息）没有混进来。
4. **合规边界**：
   - 论文不含姓名、学号、学校；
   - 没有编造问卷或访谈数据，实证部分标为"待补"；
   - 参考文献 9 条真实著作 + 1 条明确标注"待补"；
   - 2 条外部链接标注"示例链接，未核验"。
5. **可编辑交付**：PDF 用于打印，docx / pptx 保留可编辑结构。

## 五、复现说明

本示例的技能执行路径：

1. `SKILL.md` 建档与排期；
2. `references/intake.md` 清点四类输入；
3. `references/research.md` 检索与来源分级（示例中标注了未核验链接）；
4. `references/outputs.md` 生成清单、PDF、PPT、论文、Word；
5. `references/integrity.md` 做引用、隐私与越界检查；
6. 文件生成链路：Markdown → pandoc 生成 docx → LibreOffice 转 PDF；PPT 用 python-pptx 生成，口播稿写入备注栏。

# 外部检索与来源分级

## 1. 检索顺序（不要跳步）

1. 用户上传的重点资料
2. 课程大纲 / 教学日历 / 考核要求（最关键：决定考什么）
3. 教材目录、出版社配套资源、课后习题答案
4. 公开课与视频讲解
5. 学长学姐经验帖、课程评价
6. 历年真题与同类分享资料
7. 学术文献（用于论文选题与综述，摘要级即可）

原因：前四步决定"考什么"，后三步只解决"怎么讲清楚"和"有没有现成题"。

## 2. 检索词模板

把 `<课程名>`、`<教材名>`、`<老师姓名>`、`<学校>` 替换成用户提供的信息。

| 目标 | 检索词 |
|---|---|
| 考核重点 | `<课程名> 期末 重点`；`<课程名> 考点 总结` |
| 真题 | `<课程名> 历年真题 <学校>`；`<课程名> 期末试卷` |
| 课程大纲 | `<学校> <课程名> 教学大纲`；`<课程名> syllabus` |
| 教材配套 | `<教材名> <作者> 课后习题 答案`；`<教材名> 笔记 框架` |
| 视频讲解 | `<课程名> 期末 速成 site:bilibili.com`；`<课程名> 考点 讲解` |
| 经验帖 | `<学校> <课程名> 期末 怎么复习`；`<课程名> 水课 给分` |
| 论文选题 | `<课程名> 课程论文 选题`；`<主题关键词> 研究综述` |
| 作品参考 | `<课程名> 大作业 优秀作品`；`<作品类型> 分镜 案例` |

## 3. 来源分级

| 级别 | 来源 | 用途 | 注意 |
|---|---|---|---|
| A | 老师课件、教学大纲、指定教材、学校教务文件 | 定结论、定范围 | 最高优先级，冲突时以 A 为准 |
| B | 出版社配套资源、中国大学 MOOC / 学堂在线等公开课、正规机构讲义 | 补解释、补例题 | 核对是否同一版教材 |
| C | B 站 / 知乎 / 小红书 / 贴吧 / 豆瓣 / 校园论坛 / 学长资料 | 找线索、找题型、判断给分风格 | 不直接当结论；至少两个独立来源互证 |

论文类额外区分：期刊论文与学位论文可作文献综述来源；营销号、AI 生成的"资料站"不作为引用来源。

## 4. 检索记录表（写进资料清单）

| # | 标题 | 平台/来源 | 链接 | 访问日期 | 可用内容 | 可信度 |
|---|---|---|---|---|---|---|
| 1 | XX 课程期末重点 | B 站 | https://... | 2026-10-20 | 第 3、5 章考点清单 | C（与 A 级课件交叉验证一致） |

规则：

- 链接必须真实可访问，不确定就不写。
- 只记录**实际看过并用了**的内容，不堆砌链接。
- 同一考点至少两个来源时，标注"已互证"。

## 5. 版权与合规

- 不整段复制课件、教材、他人笔记；提炼后用**自己的话**写，标注出处。
- 不抓取付费墙、付费文库内容；需要时给替代方案（公开课、图书馆资源、教材原书）。
- 图片、图表优先自绘或使用明确授权的素材；不确定授权就改成文字表格。
- 用户上传的课件仅用于本次整理，不对外分发。

## 6. 失败降级

| 情况 | 做法 |
|---|---|
| 无联网能力 | 明确告知；只用用户资料产出；额外给"待补资料清单"（去哪找、搜什么词） |
| 检索无结果 | 写"未找到公开资料"，给出可替代的检索词与平台，不编造 |
| 只有 C 级来源 | 结论标注"经验帖口径，未经官方确认"，并提示用户向老师/助教核实 |
| 教材版本不明 | 按章名对应，不写具体页码 |
| 信息相互矛盾 | 以 A 级为准，列出分歧点，让用户确认 |

## 7. 时效性

- 课程评价、给分风格、真题：优先近 3 年。
- 教材与考纲：优先当前学期；老版本标注"版本可能已更新"。
- 每个外部结论都带上"截至 <日期>"，避免过期信息被当成事实。
